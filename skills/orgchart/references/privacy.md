# Privacy

Never include compensation, performance, personal contact or protected data.
Chart only people the user is allowed to see and use only necessary fields.
Workday security decides what the user can see: never widen it, never try other
IDs or another system after a refusal, and never chart another person's
organization on someone's behalf. Saved Workday pages and assembled rosters are
working files; delete them when the deck is done.
Keep working files local, in a location appropriate for the data, and delete
them when done. Confirm the destination and sharing before creating a deck.
The optional sensitive-field switches in the underlying engine do not override
this skill's privacy rule.
