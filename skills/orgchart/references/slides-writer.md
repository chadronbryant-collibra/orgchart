# Native Slides writer

1. Verify the destination account and access. Inspect and copy the selected
   template into the user's Drive, or create a blank presentation for neutral.
   Inspect page size and reserved template areas; adjust and revalidate geometry.
2. Use normalized data and validated geometry. Create editable native cards with
   stable IDs and readable text. Account for every position; identify repeated
   drilldown context and exclude it from totals. Add a legend only for meanings
   actually shown, using text or patterns as well as color.
3. In one batched Slides update create pages, cards and attached native lines.
   For rectangular cards the connection sites are top 0, left 1, bottom 2,
   right 3. Use attached STRAIGHT lines; only use BENT after a canary on the
   exact deck. Keep lines behind cards and check for overlap.
4. Read back page, card and connector counts, object IDs and endpoint sites.
   Check actual endpoint coordinates, not site indexes alone. Inspect every
   slide for readable text and completeness. On a disposable card, move and
   restore it and verify the attached line follows. Report separately any check
   that cannot be performed; don't claim attachment solely from local geometry.
5. Return the deck link and the checks completed. If the writer is unavailable,
   return the local preview and explain that no deck was created. If a write
   outcome is uncertain, inspect the same deck before retrying.
