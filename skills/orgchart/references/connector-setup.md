# Connector setup

## How Claude checks itself

Look in the session for Google Drive file copy tools and Google Slides read and
batch update tools. Say what you found in one line, for example: "Drive copy:
present. Slides batch update: missing." Check Google Sheets reads and Workday
(your profile, manager, reporting chain, direct reports) only if the chart
needs them. A connector that is listed does not prove access to a specific file
or person.

If Drive or Slides is missing, share the steps below and offer a text preview
in the meantime. A preview is not a created deck.

## Set up in Claude Desktop or claude.ai

1. Open Claude.
2. Select Customize.
3. Select Connectors.
4. Find Google Drive and select Connect.
5. Sign in with your work Google account and allow access.
6. Repeat steps 4 and 5 for Google Slides. Do the same for Google Sheets and
   Workday if you want them.
7. Start a new chat so the tools load.

Collibra employees can find a guide with screenshots in the People Solutions
Confluence space: "Use Google Docs, Sheets, Slides and Drive with Claude".

## Set up in Claude Code

Connectors added to your Claude account also appear in Claude Code. Type `/mcp`
to check. If they are missing, sign in to the same Claude account you used in
Claude Desktop, then start a new session.

## If a connector is missing or greyed out

Your admin controls which connectors you can use. Ask your IT or AI team. Please
don't work around it. Until it's sorted, you can still give Claude a roster and
get a text preview.
