# Connector setup

Check the tools actually available in the session for Google Drive file copy
and Google Slides read and batch update. Confirm the account and destination.
Check for Google Sheets reads and Workday self-profile, manager, reporting chain
and direct reports only if needed. A listed connector does not by itself prove
access to a specific file or person.

In Claude Desktop open Settings > Connectors, enable Google Drive and Google
Slides, and sign in with your work Google account. Enable Google Sheets or
Workday if needed and available. In Claude Code use the same connectors via the
desktop app or `/mcp`; inspect the tools that become available.

If a connector is blocked by an administrator, ask the administrator about the
approved route. Do not bypass the block. You can use a supplied roster and the
local preview while access is unresolved; a preview is not a created deck.
