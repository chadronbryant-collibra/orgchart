# Org chart

Draft: build or update editable Google Slides org charts from an authorized
roster, Workday reporting line, Google Sheet, CSV or pasted list. Preview a
text outline and page plan locally before creating a deck.

## Install

For Claude Code, run `./install.sh`, then start a new session if needed.
For Claude Desktop, run `python3 scripts/build_desktop_zip.py` and upload
`dist/orgchart.zip` as a skill. See [installation](docs/INSTALL.md).

## Quick start

Ask `/orgchart` and share your purpose, audience, date and permitted roster.
Try `/orgchart templates`, `/orgchart update <deck link>`, or `/orgchart help`.
The [five-minute walkthrough](docs/WALKTHROUGH.md) uses a synthetic starter.

Choose the neutral canvas or an accessible Slides template. The catalog also
contains synthetic roster starters. The Collibra template is for employees and
requires access to the shared drive.

Chart only people you are allowed to see. Do not include compensation,
performance, personal contact or protected data. Local working files may
contain people data; delete them when finished.
